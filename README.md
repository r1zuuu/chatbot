# Chatbot

## Overview

Chatbot is a web application built with Next.js and TypeScript that provides a conversational interface powered by an AI backend.

The project focuses on creating a clean and functional chat experience, with an emphasis on modern frontend architecture and reusable components.

## Features

- real-time chat interaction
- AI-powered response handling
- clean and minimal user interface
- modular project structure
- responsive frontend built with Next.js

## Tech Stack

- Next.js
- React
- TypeScript
- AI SDK
- OpenAI
- Tailwind CSS
