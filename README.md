# Chatbot

Chatbot is a web application built with Next.js and TypeScript that provides a simple conversational interface powered by an AI backend.

The project focuses on the core user experience of a chat-based assistant: sending messages, displaying responses in real time, and maintaining a clear and minimal interface. It serves as a practical implementation of a modern AI-enabled frontend built with the App Router architecture.

## Features

- real-time chat interaction
- clean conversational interface
- automatic scrolling to the latest message
- modular frontend structure based on Next.js
- integration with AI SDK tools for message handling

## Tech Stack

- Next.js
- React
- TypeScript
- AI SDK
- OpenAI integration
- Tailwind CSS

## Project Structure

The application is organized into a clear frontend structure with separate directories for the main app, shared utilities, and public assets. This makes the codebase easier to maintain and extend.
